# メビウスの帯 工作キット

メビウスの帯とその変種を作って、なぞって、切って確かめる実験工作キット（単体HTMLアプリ）です。本人がGemini Canvasで作った試作を発展させ、実寸印刷と切断実験まで含めた仕様に育てました。

## 変種（4種）

1. **基本のメビウスの帯**（半回ひねり180°）― 中心切り用・1/3切り用の帯2本と記録欄
2. **3半回ひねり（540°）の帯** ― 切ると三つ葉結び目（トレフォイル）になる実験つき
3. **2重メビウスの帯** ― 2枚重ねて一緒にひねると、実は1本の長い帯になる驚きを確かめる
4. **挑戦編：クラインの壺もどき** ― メビウスの帯2枚を縁同士で貼る（近似模型であることを明記）

## 型紙の工夫

- A4判・横向き、300dpi画像書き出し、5cm較正線つき。帯は長さ250mm×幅38mm、のりしろ対応記号（A）明示
- 歩く向きの矢印（上に点つき）― 一周すると上下逆転＝向きの反転が目で追える
- 縁の印（上縁●・下縁▲）― 組み立てると1本につながることを印刷物でも確かめられる
- 切断ガイド（中心線／1/3線）と「よそう→けっか」の記録欄を同じシートに印刷
- アプリ側の実験カードは、結果がボタンで隠れた「予想→結果」形式

## 位相幾何学の検証について

結果の記述は、`verify-topology.js` / `verify-topology2.js`（帯の3D埋め込みモデル＋フレーム平行輸送＋Gauss絡み数積分）で検証したものだけを掲載しています。

- 原帯 n=0〜3：ひねり数・片面/両面・縁の数が理論どおり
- 中心切り（n=1）：1本の帯、Lk（中心線と縁の絡み数）= −2 → **4半回ひねり**・両面
- 1/3切り（n=1）：中央=メビウスの帯、外側=4半回ひねり、2本の絡み数 −1 → **鎖状に絡む**
- 中心切り（n=3）：中心線が経線2巻き・子午線3巻きの (2,3) トーラス結び目 = **三つ葉結び目**（傾けた射影でも交点数3を確認）
- 1/3切り（n=3）：中央=3半回の帯、外側=三つ葉結び目の帯、絡み数 −3 → 絡み合う
- 2重メビウス：合体した帯は **2半回ひねり・両面・縁2本**（= 1本の帯）

注：切断後の帯の「ひねり数」は、中心線の波打ち（writhe）と相互に移り合うため、帯の縁との絡み数 Lk（= Tw + Wr、Călugăreanuの定理）で数えるのが不変量として正しく、n=1中心切りの古典的な「4半回」と一致します。540°帯については結び目の有無のみを述べ、ひねり数の断定は避けています。
